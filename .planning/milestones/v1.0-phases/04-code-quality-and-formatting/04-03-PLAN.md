<task type="auto">
  <name>Task 1: Create pre-commit configuration</name>
  <files>.pre-commit-config.yaml</files>
  <action>
Create `.pre-commit-config.yaml` in the project root with the following exact content:

```yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.15.4
    hooks:
      - id: ruff-check
        args: [--fix]
      - id: ruff-format

  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v6.0.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
      - id: check-merge-conflict
      - id: check-added-large-files
      - id: check-toml
      - id: debug-statements
```

**Version pinning:** `v0.15.4` matches the ruff version installed in the project. `v6.0.0` is the latest pre-commit-hooks release. Both pinned to specific tags for reproducibility.

**Hook ordering:** ruff-check runs first (lint + auto-fix), then ruff-format (format any changes), then hygiene hooks. This ensures lint fixes are formatted before commit.

After creating the file, verify it works:

```bash
# Install pre-commit (as a tool, not project dependency)
uv tool install pre-commit

# Run against all files to verify clean state
pre-commit run --all-files
```

If any hooks fail, fix the issues. The codebase should be clean after Plans 01+02, so failures indicate either:
- Trailing whitespace in non-Python files (fix the file)
- Missing newline at end of file (fix the file)
- YAML/TOML syntax issues (fix the file)

Commit:
```bash
git add .pre-commit-config.yaml
# Also stage any files fixed by pre-commit hooks (trailing whitespace, etc.)
git add -A
git commit -m "chore: add pre-commit hooks (ruff, trailing-whitespace, check-yaml, etc.)"
```

Read the current `.github/workflows/ci.yml` and update the `lint` job to add two new steps:

1. **ruff format check** — add `uv run ruff format --check .` as a step after the existing `ruff check` step
2. **pre-commit run** — add a step that installs pre-commit and runs it against all files

The updated lint job should look like:

```yaml
  lint:
    name: Lint (ruff)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6

      - name: Install uv and Python
        uses: astral-sh/setup-uv@v7
        with:
          python-version: "3.12"
          enable-cache: true

      - name: Install project
        run: uv sync --locked --group test

      - name: Run ruff check
        run: uv run ruff check .

      - name: Run ruff format check
        run: uv run ruff format --check .

      - name: Run pre-commit
        run: |
          uv tool install pre-commit
          pre-commit run --all-files
```

**Important:** Preserve ALL other jobs in the workflow file (test matrix, etc.) exactly as they are. Only modify the `lint` job. Read the full CI file before editing to understand its structure.

**Step 1: Fix bare except handlers (CQ-01)**

In `src/kotti/alembic/env.py`, replace:
```python
except:  # noqa: E722
```
with:
```python
except Exception:
```
(This catches all non-system exceptions while allowing SystemExit/KeyboardInterrupt to propagate. The `traceback.print_exc()` + `transaction.abort()` pattern handles logging and rollback.)

In `src/kotti/views/cache.py`, replace:
```python
except:  # noqa: E722
```
with:
```python
except Exception:
```
(Defensive catch for user-provided caching policy callable. `except Exception` prevents bad plugins from breaking responses while still allowing system exits.)

**Step 2: Fix E721 type comparisons (unsafe fixes, review each)**

Run `uv run ruff check --select E721 .` to find all 6 violations. For each one:
- If comparing with `type(x) == SomeType`, replace with `isinstance(x, SomeType)`
- Review each to ensure the original intent was type checking (not identity checking)

Apply via: `uv run ruff check --fix --unsafe-fixes --select E721 .`
Then manually review the diff (`git diff`) to verify correctness.

**Step 3: Fix RUF059 unused unpacked variables (unsafe fixes, review each)**

Run `uv run ruff check --select RUF059 .` to find all ~55 violations.

Apply via: `uv run ruff check --fix --unsafe-fixes --select RUF059 .`
Then manually review the diff — each renamed variable (e.g., `email1` -> `_email1`) must not be referenced later in the same scope.

Run tests after this step: `uv run pytest -x -q`

**Step 4: Fix F841 unused local variables**

Run `uv run ruff check --select F841 .` to find all 4 violations. For each:
- If the assignment has a side effect (function call), keep the call but remove the variable assignment
- If the variable is truly dead code, remove the entire line

**Step 5: Fix B904 raise-without-from**

Run `uv run ruff check --select B904 .` to find all 5 violations. For each `raise` inside an `except` block:
- If re-raising a different exception, add `from exc` (where `exc` is the caught exception variable)
- If raising a new exception unrelated to the caught one, add `from None` to suppress the implicit chaining

**Step 6: Fix B015 pointless comparisons**

Run `uv run ruff check --select B015 .` to find violations. Read each case in context:
- If the comparison was meant to be an assertion, add `assert` keyword
- If it was testing that code doesn't crash (no-op expression), add a comment explaining intent

**Step 7: Fix B028 warnings without stacklevel**

Run `uv run ruff check --select B028 .` to find all 4 violations. Add `stacklevel=2` to each `warnings.warn()` call that is missing it. This ensures the warning points to the caller, not the function issuing the warning.

**Step 8: Fix RUF012 mutable class attributes**

Run `uv run ruff check --select RUF012 .` to find all 4 violations. For each mutable class attribute without a type annotation:
- Add a `ClassVar[...]` type annotation, OR
- Add a `# noqa: RUF012` comment if the attribute is intentionally mutable (e.g., SQLAlchemy declarative model attributes that SQLAlchemy manages)

NOTE: SQLAlchemy model attributes that look like mutable class attrs (e.g., `__acl__`, `type_info`) are managed by the ORM framework. These should get `# noqa: RUF012` rather than ClassVar annotations which would confuse SQLAlchemy.

**Step 9: Fix E501 long lines**

Run `uv run ruff check --select E501 .` to find all 7 violations. For each:
- If it's a long string/URL in a comment, break the line or shorten
- If it's a long function signature, add line breaks at parameter boundaries
- If it's a long import, the import should already be sorted; wrap it

**Step 10: Clean up stale noqa comments (MUST BE LAST)**

After ALL other violations are fixed, stale `# noqa:` comments will be flagged by RUF100:
```bash
uv run ruff check --fix --select RUF100 .
```

This removes noqa comments that no longer suppress any active violation (e.g., the `# noqa: E722` on the bare excepts we just fixed).

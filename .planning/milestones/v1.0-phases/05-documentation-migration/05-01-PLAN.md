   Under `[project.optional-dependencies]`:
   ```toml

       "mkdocs-material[imaging]>=9.5",
       "mkdocstrings[python]>=0.24",
       "mike>=2.0",
   ]
   ```

   Under `[dependency-groups]` (if it mirrors the docs group), update similarly:
   ```toml
   docs = [
       "mkdocs-material[imaging]>=9.5",
       "mkdocstrings[python]>=0.24",
       "mike>=2.0",
   ]
   ```

2. Remove any existing `rtd.txt` or ReadTheDocs requirements files if they exist.

3. Create `.readthedocs.yaml` at project root:
   ```yaml
   version: 2

   build:
     os: "ubuntu-22.04"
     tools:
       python: "3.12"

   mkdocs:
     configuration: mkdocs.yml

   python:
     install:
       - method: pip
         path: .
         extra_requirements:
           - docs
   ```

4. Run `uv lock` to update the lockfile with the new docs dependencies.

5. Install the docs deps locally: `uv sync --group docs` (or `uv pip install -e ".[docs]"`) so that `mkdocs build` can run.

6. Run `mkdocs build --strict` to verify the scaffolded site builds cleanly. Fix any errors. Common issues:
   - Missing files referenced in nav → ensure all stub files exist
   - Plugin errors → ensure mkdocstrings is installed
   - YAML syntax errors in mkdocs.yml → validate carefully

   Note: The stub API pages do NOT have `::: module` directives yet, so mkdocstrings will not attempt to import kotti modules. The build should pass with just placeholder text.

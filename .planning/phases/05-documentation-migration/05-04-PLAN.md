1. **Enable social cards plugin.** In `mkdocs.yml`, uncomment the social plugin and configure:
   ```yaml
   plugins:
     - search
     - social:
         enabled: !ENV [CI, false]
   ```
   The `!ENV [CI, false]` ensures social cards are only generated in CI (ReadTheDocs, GitHub Actions) where cairosvg system deps are available. Local `mkdocs serve` skips it.

2. **Enable mike version provider.** Uncomment the version block in `extra:`:
   ```yaml
   extra:
     version:
       provider: mike
       alias: true
       default: stable
   ```
   Note: This configures the version selector UI widget. The actual mike deployment (gh-pages push) is deferred to future work per research open question #3. RTD will build from master with the current version.

3. **Verify mkdocs.yml is valid** — `mkdocs build --strict` should still pass. If the social plugin causes issues locally (missing cairosvg), confirm the `!ENV [CI, false]` disables it.

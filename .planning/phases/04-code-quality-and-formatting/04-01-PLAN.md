**Step 2: Apply ruff formatting to entire codebase (ISOLATED COMMIT)**

This step MUST produce exactly one commit containing ONLY formatting changes. No lint fixes, no config changes in this commit.

```bash
# First, commit the config changes from Step 1
git add pyproject.toml
git commit -m "chore: expand ruff config to full ruleset (E,W,F,I,B,UP,SIM,RUF)"

# Now apply formatting ONLY
uv run ruff format .

# Verify formatting changed files
git diff --stat

# Stage all formatting changes
git add -A

# Create the isolated formatting commit
git commit -m "style: apply ruff format to entire codebase

Automated formatting pass with ruff format (line-length=88).
This commit is added to .git-blame-ignore-revs to preserve blame history."
```

**Step 3: Set up git-blame-ignore-revs**

Immediately after the formatting commit:

```bash
# Capture the formatting commit SHA
FORMATTING_SHA=$(git rev-parse HEAD)

# Create .git-blame-ignore-revs
cat > .git-blame-ignore-revs << EOF
# Formatting-only commit: ruff format applied to entire codebase
$FORMATTING_SHA
EOF

# Add export-ignore to .gitattributes (create if needed, append if exists)
# Check if .gitattributes exists and if the line is already present
if [ -f .gitattributes ]; then
    grep -q "git-blame-ignore-revs" .gitattributes || echo ".git-blame-ignore-revs export-ignore" >> .gitattributes
else
    echo ".git-blame-ignore-revs export-ignore" >> .gitattributes
fi

# Configure local git to use the file
git config blame.ignoreRevsFile .git-blame-ignore-revs

# Commit the blame infrastructure
git add .git-blame-ignore-revs .gitattributes
git commit -m "chore: add .git-blame-ignore-revs for formatting commit"
```

**CRITICAL ordering:** Config commit -> Format commit -> Blame-ignore commit. Three separate commits. The format commit MUST contain nothing but formatting changes.
